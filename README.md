# SKY Barbearia

Landing page institucional premium da **SKY Barbearia & Especialista em Visagismo PB**, localizada em Manaíra, João Pessoa.

## Sobre o projeto

A página foi projetada para apresentar a experiência SKY, destacar o visagismo como diferencial e transformar visitantes em agendamentos. O conteúdo reúne informações públicas do Google Maps e do Instagram oficial da marca.

### Principais seções

- Hero com posicionamento de marca e CTA de agendamento
- Experiência SKY e diferenciais
- Serviços: corte, barba, visagismo, prótese capilar, Spa do Noivo e SKY Kids
- Processo de atendimento com visagismo
- Prova social com nota 5,0 e avaliações reais
- Endereço, horários, telefone e rotas
- Layout totalmente responsivo

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide Icons

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Build

```bash
npm run build
```
